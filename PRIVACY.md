# Privacy

SideStash is local-only software.

- It does not send files, file names, paths, analytics, or usage data to any server.
- Stashed files are stored on disk under `~/Library/Application Support/SideStash/Stash/`.
- A local `.metadata.json` file records original file paths so SideStash can restore files after drag-out operations.
- Optional Finder integration may require macOS Accessibility permission.

Removing the stash folder deletes SideStash's local file stash and metadata.
